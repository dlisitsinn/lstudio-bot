# LStudio — поиск клиентов без сайта

Бот для веб-студии LStudio: находит организации без собственного сайта (ВКонтакте, OpenStreetMap, таблицы из 2ГИС и Яндекс Карт), готовит персональные письма и сообщения, отправляет письма на почту и помогает писать во ВК.

**Установка и работа — в файле [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).**

Бот сам обновляется при каждом запуске: скачивает последнюю версию из этого репозитория. Личные данные (`.env` с почтой и токенами, папка `data` с базой и вашими текстами) сюда никогда не попадают и при обновлении не меняются.
